# Course Registration System

## Stack
- Python (Django, stable LTS)
- Django templates, HTML, CSS, minimal vanilla JS
- SQLite (dev), PostgreSQL (deploy)
- Render (hosting), GitHub (VCS)

## Key Business Rules
- Admin: Secure login, manage courses, view students/registrations
- Student: Unique signup, register for level-matched courses, one final submission
- No course edits after submission; admin corrections only
- Permissions and business rules enforced server-side

## Working Guidelines
- Read docs before changes
- Work only on requested milestone
- Inspect code before editing
- Use Django built-ins where possible
- Validate permissions/rules on server
- Never store/print secrets
- Never weaken tests to pass
- Only report actual test/command runs
- Update progress after milestones
- No deploy/push/data deletion/git rewrite unless instructed
